# testing_phase — Vintage Finvest

Boutique financial services firm and family office web application.

## Tech Stack
- **Build Tool**: Vite 5
- **Languages**: HTML5, Vanilla CSS3, Modern JavaScript (ES6+ Modules)
- **Features**: Interactive Portfolio Studio, Canvas 2D Particle Engine, Multi-Page Architecture (MPA)

## Getting Started

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
